Modélisation 3D d'un aileron arrière de Formule 1

En terminale, j’ai modélisé un aileron arrière de F1 pour mon projet de sciences de l’ingénieur. On peut le faire tourner ici pour voir comment les profils de l’aile rejoignent les deux dérives latérales.

Examiner l’aileron

Télécharger le modèle 3D (GLB, 1,8 Mo)

Aperçu de l’aileron. Le fichier GLB peut aussi s’ouvrir dans une visionneuse 3D.

J’ai converti mon fichier de CAO au format STEP en GLB pour que l’assemblage soit consultable dans un navigateur.

Pourquoi un aileron de F1 ?

Je suis le sport automobile depuis longtemps. Pour ce projet, j’ai choisi une pièce qu’on distingue même de loin sur une monoplace. De près, on voit que la silhouette de l’aileron tient à plusieurs formes assemblées.

À regarder dans le modèle

En vue de face, on distingue les profils superposés de l’aile. Fais pivoter l’assemblage d’un quart de tour pour retrouver les découpes et les ouvertures sur les dérives.

La suite de mon parcours

Depuis ce projet de terminale, je me suis tourné vers le développement d’applications. J’ai notamment créé La Boussole pour organiser les covoiturages de ma troupe scoute.
