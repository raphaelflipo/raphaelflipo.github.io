Jarvis

Use a conversational assistant on the device without creating an account.

Context
Jarvis is a personal project for a conversational assistant.
Problem
A local model must account for storage, available memory and first-load time.
Objective
Provide an interface for several devices and precise compatibility information.
Method
Separate the product site, web app and native editions. Test the available workflows on each platform.
My role
Develop the application and organise the published releases.
Tools
Swift, Python and MLX for the Mac edition. WebAssembly and JavaScript in the browser.
Solution
A web edition and release candidates for macOS, Windows and Android.
Verifiable results
The web edition and published assets are available from the Jarvis page. Compatibility is documented for each release.
Skills
Software development, web distribution and documentation of deployment limits.
