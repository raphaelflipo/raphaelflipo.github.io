Download Jarvis

Native downloads are test builds. Jarvis Local offers text chat. The Mac edition also includes tools for files, documents and calendars.

macOS

3.3.0-rc.1 · Apple Silicon · macOS 14+

The 722 MB disk image includes Jarvis.app, Python and Ollama. Allow about 1.5 GB for the app, plus room for your models. 16 GB of RAM is recommended.

The package uses an ad hoc signature and has neither a Developer ID certificate nor Apple notarisation. Gatekeeper blocked the package during validation. This build is for Apple Silicon Macs.

Download the disk image
Installation and testing

Open the disk image, drag Jarvis into Applications, then open the Jarvis menu and choose to install a local model. Opening the app is subject to macOS security checks.

The RC1 notes document testing on an M5 MacBook Air, including installation from the disk image, a local reply and chat history after reopening. RC1 test notes and checksums.

Windows

3.3.0-rc.2 · x64 · Windows 10+

The 125 MB EXE includes the interface and chat engine. Open the installer, follow the prompts, then load a model in Jarvis.

The installer lacks an Authenticode signature. Windows may display a warning.

Download the EXE installer
Installation and testing

RC2 was installed and tested on Windows Server 2025 in GitHub Actions, including a local reply and reopening offline. SmartScreen behaviour on a personal PC remains unverified.

Android

3.3.0-rc.2 · Android 10+ · Recent WebView

Install the signed 5.6 MB APK directly. Open the download, temporarily allow installation from that source if prompted, then open Jarvis and load a model.

The build was tested on an Android 15 x86_64 emulator. Performance on physical ARM64 phones remains unverified.

Download the APK
Installation and testing

RC2 fixes a layout issue when the keyboard is open. Tests covered upgrading from RC1 with the model and chat history preserved, plus sending a message offline.

iPhone / iPad

Safari · Installable web app

Open Jarvis in Safari. Use Share → Add to Home Screen, then download a model inside the installed web app.

A native development build launched on a physical iPhone using a personal signing profile. The public distribution archive is still awaiting an App Store or TestFlight channel.

Native app status

The native RC2 targets iOS 17 and later. The personal development profile expires after seven days. Local chat and cached model loading were also tested in an iOS 27.2 simulator. iOS distribution status.

Work with files on Mac

The Mac edition uses Ollama and can work with files, documents and tasks. You explicitly grant access to the folders and system integrations it uses.

MLX remains optional for existing setups. Development tools are required only when a task asks Jarvis to build a project.

Frequently asked questions

How do I get started?

Open the web or native app, choose a model, then select the download or load button. Wait for Jarvis to be ready before sending a message. The web app interface is in French.

Can I use Jarvis offline?

After the first download, load the model from its cache. Your browser may clear that storage if space runs low. On iPhone, download your model from the Home Screen app if that is where you plan to use it.

How do Jarvis Local and the Mac edition differ?

Jarvis Local offers text chat in a browser or in the Windows and Android builds. The Mac edition adds file tools and macOS integrations that use permissions you grant.

Data and privacy

Jarvis Local keeps the last 40 messages on your device. The model uses a shorter context. You can clear chat history and downloaded models in settings.

GitHub hosts the installers. Hugging Face and Ollama distribute models for the respective editions and receive standard network information, including your IP address. Local chat text stays on your device.

If you enable the Mac edition’s web tools or optional cloud assistance, those features use their respective providers. The local edition has no account or analytics.
