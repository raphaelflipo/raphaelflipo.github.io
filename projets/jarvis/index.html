Jarvis

Utiliser un assistant conversationnel sur son appareil, sans ouvrir de compte.

Contexte
Jarvis est un projet personnel d’assistant conversationnel.
Problème
Un modèle local doit tenir compte du stockage, de la mémoire disponible et du temps de premier chargement.
Objectif
Donner accès à une interface utilisable sur plusieurs appareils et à des informations de compatibilité précises.
Méthode
Séparer la vitrine, l’application web et les éditions natives. Tester les parcours disponibles sur chaque plateforme.
Mon rôle
Développer l’application et organiser les versions mises à disposition.
Outils
Swift, Python et MLX pour l’édition Mac. WebAssembly et JavaScript pour le navigateur.
Solution
Une édition web et des versions candidates pour macOS, Windows et Android.
Résultats vérifiables
L’édition web et les artefacts publiés sont accessibles depuis la fiche Jarvis. La compatibilité est décrite pour chaque version.
Compétences
Développement logiciel, distribution web et documentation des limites de déploiement.
