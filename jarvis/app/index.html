Installer sur cet appareil

iPhone ou iPad
Ouvrez cette page dans Safari, puis Partager → Sur l’écran d’accueil. Si besoin, activez l’ouverture comme application.

Android
Dans le menu du navigateur, choisissez Installer l’application ou Ajouter à l’écran d’accueil.

Mac ou Windows
Utilisez le bouton Installer lorsqu’il apparaît, ou l’option d’installation du navigateur. Sur Mac, Safari peut proposer Ajouter au Dock.

L’installation ajoute un accès à Jarvis. Le modèle doit ensuite être chargé dans ce navigateur. Elle ne garantit pas la compatibilité de votre appareil avec l’IA locale.

Réglages

Votre espace local

Sur cet appareil

Le modèle d’IA s’exécute dans votre navigateur. Vous n’avez besoin ni de compte, ni d’un ordinateur distant. Le téléchargement initial nécessite Internet et peut occuper beaucoup d’espace.

Le navigateur conserve les données localement. Il peut les effacer pour libérer de la place ; vous devrez alors recharger le modèle. Un navigateur ou un appareil différent utilise son propre espace.

Ce que Jarvis peut faire

Répondre à vos messages, vous aider à écrire et réfléchir à partir du texte que vous partagez. Cette version autonome n’ouvre pas vos autres applications et n’agit pas sur votre appareil.

Les résultats et la rapidité varient selon le modèle, le navigateur et le matériel. Vérifiez les informations importantes.
