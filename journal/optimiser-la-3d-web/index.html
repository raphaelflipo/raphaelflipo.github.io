Rendre un GLB explorable sans télécharger une seconde voiture

Sur téléphone, le visiteur peut lire le dossier avant de décider si le téléchargement 3D lui est utile.

Répartir les octets

Le texte et le rendu fixe sont disponibles en premier. L’activation charge le GLB et un index associé à son empreinte SHA-256. Les six index de cette version totalisent 13 636 octets avant compression HTTP. Ils décrivent à quelle famille appartient chaque triangle, indépendamment des matériaux. Le code peut donc isoler un frein sans embarquer une copie de la monoplace pour chaque sélection.

Mesurer ce que fait le visiteur

Un score obtenu sur l’accueil ne donne pas le temps d’activation de la scène. Un essai utile ouvre une page neuve, vérifie l’absence de requête GLB avant le clic, puis mesure jusqu’à la première sélection dessinée. Pour juger de la fluidité après chargement, il faut observer la rotation ou le zoom sur le matériel visé. Un rendu logiciel fournit un point de comparaison reproductible pour les modifications du site.
